# 제공된 Gymwork 기능 목록 대비 구현 범위

사용자의 요청에 따라 회원가입·로그인·회원 프로필·구독·결제는 제외합니다. 현재 버전은 기기 내 데이터와 P0 운동 기록 흐름에 초점을 둡니다. 외부 사이트의 실제 화면을 검증하지 못했으므로 UI 1:1 복제 완료로 표현하지 않습니다.

| 영역            | 현재 동작                                                                                 | 범위와 제한                                                                                                                |
| --------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 개인 운동 설정  | 목표, 주간 운동일, kg/lbs, 휴식 시간, 자동 타이머                                         | 계정 없이 기기에 저장                                                                                                      |
| 종목 라이브러리 | 3개 언어 이름·초성 검색, 부위·기구 필터, 종목별 한국어·영어·일본어 4개 항목 안내(준비·실행·호흡·주의사항) | 120종목(기존 60 + 추가 60), 기구 아이콘 제공. 일반 참고용 텍스트이며 의료·개인 맞춤 조언 아님. 추가 60종은 외부 출처로 검증하지 않음. 원본 운동 사진/시범 영상 없음 |
| 직접 등록 운동  | 운동 기록과 루틴에서 자유로운 이름 입력                                                   | 별도 영구 마스터 관리 UI 없음                                                                                              |
| 루틴            | 생성·편집·삭제·복제, 종목 순서·세트·무게·횟수 편집                                        | 기존 수행 기록은 루틴 편집 영향을 받지 않음                                                                                |
| 운동 계획       | 요일별 루틴·휴식 설정, 날짜별 예정 루틴 불러오기                                          | 추천 예시 7개·원문 링크, 날짜가 있는 주간 목록·요일 세트 자동 로딩. 전문가 콘텐츠 유료 카탈로그는 없음                     |
| 운동 세션       | 시작·종료·운동 시간, 모바일 전체화면 터치 진행·자동 종료·사진 안내, 날짜별 기록·수정·삭제 | 하루에 하나의 합산 세션                                                                                                    |
| 세트            | 중량·횟수 편집, 추가·삭제·완료, 실시간 볼륨                                               | RPE와 유산소 거리·시간 전용 필드는 미구현                                                                                  |
| 이전 기록       | 선택한 날짜 이전의 동일 종목 직전 완료 기록 재사용                                        | 불러온 세트의 완료 상태는 초기화                                                                                           |
| 휴식            | 완료 시 자동 시작, 휴식 초 설정, 수동 시작·종료                                           | 마감 시각 기준으로 백그라운드 지연 보정, 집중 모드는 같은 탭 새로고침 시 마감 시각 복원. 시스템 알림은 권한·기기 지원 필요 |
| 템플릿·추천     | 5×5, 이전 세트를 전부 완료하면 2.5kg 증량 제안                                            | 규칙 기반. AI/개인 의료·트레이너 추천 아님                                                                                 |
| 캘린더          | 완료·미완료 기록·예정·휴식·사진 표시                                                      | 날짜 이동·이전 날짜 편집 지원                                                                                              |
| 통계            | 누적 운동일·완료 세트·볼륨, 최근 8주 볼륨, 히스토리                                       | 일단위 완료 세트 기준                                                                                                      |
| 성장            | Epley 1RM 계산기, 종목별 추정 1RM 추이·PR, 3대 합산, 부위별 볼륨                          | 1~12회 세트 사용. 백분위·회복·RPE 추이는 미구현                                                                            |
| 사진            | 하루 1장 저장·교체·삭제, HEIC/HEIF 기기 내 변환, 크기·WebP 압축                           | 원본을 보존하지 않음                                                                                                       |
| 공유·백업       | 하루 공유·전체 백업, 압축 문자열·파일 내보내기, 복사·기기 파일 공유                       | 사진 포함 가능. 비밀번호 선택 시 AES-GCM 암호화. Base91 기본·Base64 호환 형식                                              |
| 복원            | 해독·형식 검증·충돌 확인 후 병합                                                          | 같은 날짜는 교체. 전체 백업의 설정도 복원                                                                                  |
| PWA             | 정적 리소스 오프라인 캐시, manifest, 홈 화면 설치                                         | HTTPS 배포 후 최초 온라인 방문 필요. 설치 메뉴는 브라우저에 따라 다름                                                      |
| 전문가·소셜·AI  | 없음                                                                                      | 전문가 원본 콘텐츠, 친구 관계·랭킹·결제·AI API는 별도 데이터/서비스 설계 필요                                              |

운동 데이터와 사진은 브라우저 IndexedDB에 저장합니다. 사이트 원점과 브라우저 프로필이 달라지면 별도 저장소로 취급됩니다. 계정 없이 다른 기기로 옮길 때는 전체 백업 문자열 또는 파일을 사용하세요.
